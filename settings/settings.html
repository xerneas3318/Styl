Google Integration
1
Open Google OAuth Playground
2
In the right panel → click the gear icon → check "Use your own OAuth credentials" is off (use Google's default).
3
In the left panel, find and select these scopes, then click Authorize APIs:
  • Gmail API v1 → …/auth/gmail.readonly
  • Calendar API v3 → …/auth/calendar
4
Click Exchange authorization code for tokens → copy the Access token value.
5
Paste it below and Save. Tokens expire in ~1 hour — repeat when needed.
